# Декларация использования ИИ

## Самостоятельно сделано:

- Выбор предметной области.
- Построение ER-диаграммы.
- Создание и заполнение базы данных.
- Подключение DBeaver.
- Написание SQL-запросов.
- Подготовка отчёта.

## ИИ использовался для:

- Генерации данных по предметной области.
- Консультации по синтаксису SQL, оптимизации запросов.
- Помощи в написании Python-скрипта для визуализации выручки по категориям и месяцам.
- Структуризации проекта, консультации по лучшему расположению файлов по папкам.
- Написания комментариев в коде.
- Помощи в составлении презентации.
- Проверки документации на наличие ошибок.
